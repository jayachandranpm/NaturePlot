# AI provider logos

Vendored, unmodified SVG files from `@lobehub/icons-static-svg@1.95.1`
([Lobe Icons](https://github.com/lobehub/lobe-icons), MIT).

`page-actions.ts` adds a CSS class and decorative accessibility attributes when
inlining these marks. Monochrome logos follow the light/dark text color; Gemini
and Claude retain their original colors. No runtime requests are needed.

The license and brand attribution are in [`docs/THIRD_PARTY.md`](../../../docs/THIRD_PARTY.md).
